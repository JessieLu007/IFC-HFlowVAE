# IFC-HFlowVAE

Official implementation of:

**IFC-HFlowVAE: A self-enhancing generative framework with structural anchoring for imbalanced clinical data augmentation**

This repository contains the implementation of IFC-HFlowVAE, a heterogeneous
tabular data generation framework for minority-class augmentation in imbalanced
clinical datasets.

IFC-HFlowVAE combines heterogeneous variational autoencoder modeling,
normalizing flow enhanced latent representation learning, and iterative
feedback-based refinement to generate synthetic tabular samples.

---

## Environment Setup

The experiments were conducted using Python and PyTorch.

Create the environment using:

```bash
conda env create -f environment.yml
conda activate hflowvae
```

For Windows systems:

```bash
conda env create -f windows_environment.yml
```

---

## Running Experiments

The main experimental pipeline is implemented through notebooks in:

```
hflow_vae/notebooks/
```

### 1. Five-fold cross-validation benchmark

Run:

```
hflow_vae/notebooks/5cvfold_run.ipynb
```

The complete pipeline can also be executed by:

```bash
python hflow_vae/ifc_core/runner.py
```

This notebook performs the complete experimental workflow:

- loading and preprocessing datasets;
- StratifiedKFold data splitting;
- training IFC-HFlowVAE and baseline augmentation methods;
- generating synthetic samples;
- training downstream classifiers;
- saving generated samples and classification results.

The generated results are saved for further analysis.

---

### 2. Train and use IFC-HFlowVAE independently

Run:

```
hflow_vae/notebooks/run_hflowvae_single.ipynb
```

This notebook provides a simplified example for directly calling the proposed
HFlowVAE model on an individual dataset.

---

### 3. Analyze experimental results

Run:

```
hflow_vae/notebooks/results_analysis.ipynb
```

This notebook analyzes the results generated by
`5cvfold_run.ipynb`, including:

- aggregation of classification results;
- comparison between augmentation methods;
- statistical analysis;
- visualization.

## Dataset Preparation

The original datasets should be placed in:

```
hflow_vae/data/original/
```

Missing values in the original datasets should be preserved.

Dataset-specific information is defined in:

```
hflow_vae/data/datasets_info.json
```

For a custom dataset, users should add the corresponding information,
including:

- categorical attributes;
- numerical attributes;
- target column;
- whether missing values exist.

Example:

```json
"hepatitis": {
    "categorical": [
        "sex", "steroid", "antivirals", "fatigue", "malaise", "anorexia", "liver_big",
        "liver_firm", "spleen_palpable", "spiders", "ascites", "varices", "histology"
    ],
    "numerical": [
        "age", "bilirubin", "alk_phosphate",
        "sgot", "albumin", "protime"
    ],
    "target": "label",
    "has_missing": true
}
```


## Baseline Methods

Baseline implementations are located in:

```
hflow_vae/generators/baselines/
```

They are integrated with the same StratifiedKFold splitting and evaluation
pipeline used for IFC-HFlowVAE.

## Additional Notes

### TabKDE

The implementation in:

```
hflow_vae/tabkde/
```

is adapted from the original TabKDE implementation to be compatible with the
preprocessing pipeline used in this repository.

---

### ForestDiffusion

The file:

```
hflow_vae/diffusion_with_trees_class.py
```

contains a small modification for the ForestDiffusion baseline.

The modification handles unseen categorical values after data splitting by
assigning them to the most frequent category value.

When reproducing ForestDiffusion experiments, replace the corresponding file
in the original ForestDiffusion package with this modified version.
