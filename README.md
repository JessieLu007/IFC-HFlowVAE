# IFC-HFlowVAE

Official implementation of:

**IFC-HFlowVAE: A self-enhancing generative framework with structural anchoring for imbalanced clinical data augmentation**

This repository provides the implementation of IFC-HFlowVAE, a heterogeneous
tabular data generation framework designed for minority-class augmentation in
imbalanced clinical datasets.

IFC-HFlowVAE integrates heterogeneous variational autoencoder modeling,
normalizing flow enhanced latent representation learning, and iterative
feedback-based refinement to generate high-quality synthetic tabular samples
while preserving complex minority-class patterns.

The generated synthetic samples can be used for downstream classification tasks
under class imbalance scenarios.

---


### `hflow_vae/data`

This directory contains dataset-related files and preprocessing utilities.

- `original/`: stores the original clinical datasets used in experiments.
  Original missing values are preserved when they exist in the source datasets.

- `Info/`: contains dataset description files required by the TabKDE baseline
  method.

- `data_processor.py`: implements the data preprocessing pipeline, including
  processing of numerical and categorical attributes.

- `datasets_info.json`: stores dataset metadata required by the preprocessing
  pipeline. Users applying the framework to custom datasets should add the
  corresponding dataset information to this file.

Each dataset entry should specify categorical attributes, numerical attributes,
target column, and missing-value information. For example:

```json
"hepatitis": {
    "categorical": [
        "sex", "steroid", "antivirals", "fatigue",
        "malaise", "anorexia", "liver_big",
        "liver_firm", "spleen_palpable",
        "spiders", "ascites", "varices",
        "histology"
    ],
    "numerical": [
        "age", "bilirubin", "alk_phosphate",
        "sgot", "albumin", "protime"
    ],
    "target": "label",
    "has_missing": true
}
````

### `hflow_vae/evaluation`

Contains classification evaluation and synthetic data evaluation implementations.

This directory includes the evaluation procedures used to measure downstream
classification performance and synthetic data quality.

---

### `hflow_vae/experiments`

Stores aggregated experimental results generated from the benchmark experiments.

The final classification results are saved in parquet format. These summary
files are included in the repository because their size is relatively small
and they can be directly used for result analysis and visualization.

---

### `hflow_vae/generators`

Contains the implementation interfaces for synthetic data generation methods.

The directory:

```
hflow_vae/generators/baselines/
```

contains the calling implementations of baseline augmentation methods.

All baseline methods are integrated into the same StratifiedKFold-based
experimental pipeline used by IFC-HFlowVAE to ensure consistent data splitting
and evaluation.

---

### `hflow_vae/hetero_vae`

Contains the implementation of the proposed HFlowVAE model, including:

* heterogeneous encoder and decoder components;
* latent representation learning;
* normalizing flow components;
* loss computation and optimization modules.

---

### `hflow_vae/ifc_core`

Contains the implementation of the IFC training framework.

The complete experimental pipeline can be executed through:

```bash
python hflow_vae/ifc_core/runner.py
```

The script runs:

```python
if __name__ == "__main__":
    run_all()
```

which executes the complete benchmark workflow, including data processing,
model training, synthetic sample generation, and downstream evaluation.

---

### `hflow_vae/notebooks`

Contains interactive notebooks for running experiments and analyzing results.

The main notebooks are:

#### `5cvfold_run.ipynb`

Runs the complete five-fold cross-validation experiments.

This notebook performs:

* dataset preprocessing;
* StratifiedKFold splitting;
* training of IFC-HFlowVAE and baseline augmentation methods;
* synthetic sample generation;
* downstream classification evaluation;
* saving generated samples and experimental results.

---

#### `run_hflowvae_single.ipynb`

Provides an independent example for directly training and applying the proposed
HFlowVAE model.

It can be used to:

* train IFC-HFlowVAE on an individual dataset;
* generate synthetic samples;
* inspect model behavior without running the complete benchmark pipeline.

---

#### `results_analysis.ipynb`

Analyzes and visualizes the experimental results generated by
`5cvfold_run.ipynb`.

The analysis includes:

* aggregation of classification results;
* comparison between augmentation methods;
* statistical analysis;
* visualization of experimental outcomes.

---

### `hflow_vae/process`

Contains auxiliary functions for result processing and visualization.

These functions are used together with modules in
`hflow_vae/evaluation`.

---

### `hflow_vae/result_analysis`

Contains intermediate analysis scripts used during development.

These files are not required for reproducing the final experimental results.

---

### `hflow_vae/tabkde`

Contains the TabKDE baseline implementation.

The original TabKDE implementation was modified to integrate with the data
preprocessing and loading pipeline used in this repository. Therefore, the
adapted implementation is included locally.

---

### `hflow_vae/utils`

Contains general utility functions shared across different modules.

---

### `hflow_vae/diffusion_with_trees_class.py`

This file contains a modified implementation related to the ForestDiffusion
baseline.

Clinical tabular datasets often contain highly imbalanced categorical
attributes. After data splitting, some categorical values may appear only in
the training or validation subset, which can cause errors in the original
ForestDiffusion implementation.

To address this issue, the corresponding code used by the baseline generator
was modified. For unseen categorical values, the implementation assigns the
most frequent category value.

When reproducing the ForestDiffusion baseline, this modified file should
replace the corresponding file in the original ForestDiffusion package.

## Installation

The experiments were conducted using Python and PyTorch.

We recommend creating the environment using:

```bash
conda env create -f environment.yml
conda activate hflowvae
```

For Windows systems:

```bash
conda env create -f windows_environment.yml
```

---

## Dataset Preparation

The experiments use seven publicly available clinical tabular datasets.

Due to the distribution policies of the original datasets, the raw datasets are
not included from external sources. Users should download the datasets from
their corresponding sources and place them in:

```
hflow_vae/data/original/
```

Before running experiments, dataset information should be specified in:

```
hflow_vae/data/datasets_info.json
```

---

## Reproducing Experiments

The complete experimental workflow can be reproduced using:

```
hflow_vae/notebooks/5cvfold_run.ipynb
```

or:

```bash
python hflow_vae/ifc_core/runner.py
```

The generated synthetic samples and classification results will be saved during
execution and can subsequently be analyzed using:

```
hflow_vae/notebooks/results_analysis.ipynb
```

---

## Evaluation

The framework evaluates synthetic samples from two perspectives.

### Synthetic Data Fidelity

The generated samples are evaluated using statistical and structural metrics,
including:

* marginal distribution similarity;
* feature dependency preservation;
* manifold-level fidelity measurements.

### Downstream Utility

Synthetic samples are evaluated through downstream classification tasks using
different classifiers under imbalanced learning scenarios.

---

## Reproducibility

All experiments reported in the manuscript were conducted using the provided
implementation and environment configuration.

To facilitate reproducibility:

* identical data splitting strategies are applied across methods;
* fixed random seeds are used during experiments;
* generated samples and experimental results are saved after execution.
